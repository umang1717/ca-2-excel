
# Electric Vehicle Population

## 📘 Project Overview

This project explores the growth and distribution of Electric Vehicles (EVs) across different regions. It aims to analyze patterns in EV adoption, understand influencing factors such as policy, infrastructure, and population density, and provide actionable insights to encourage sustainable transportation.

## 🔍 Objectives

- Analyze trends in electric vehicle registration.
- Visualize regional adoption rates of EVs.
- Identify key factors driving or hindering EV adoption.
- Predict future EV population growth using data analytics or machine learning.

## 🛠️ Technologies Used

- **Programming Language**: Python
- **Libraries**: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Database**: SQLite / CSV
- **Visualization Tools**: Power BI / Tableau / Python libraries
- **IDE**: Jupyter Notebook / VS Code

## 📊 Data Sources

- Government EV registration databases (e.g., data.gov)
- Public EV datasets from Kaggle or other open data platforms
- Charging infrastructure databases (optional)

## 📈 Key Features

- Year-wise and state-wise EV population trends.
- Correlation analysis with factors like fuel price, income, and policy incentives.
- Forecasting future EV population using regression models.
- Interactive dashboards for insights presentation.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/electric-vehicle-population.git
   cd electric-vehicle-population
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the analysis:
   ```bash
   jupyter notebook
   ```
